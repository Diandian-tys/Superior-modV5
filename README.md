
玩法简介
这是一套以超人能力为核心的生存/创造向玩法包。玩家通过注射获得「TU_HERO」身份后，将拥有超人体质、自由飞行、多种主动技能与实验室系统。
整体风格混合了经典超人能力与部分《黑袍纠察队》式的英雄道具，并额外加入比扎罗（Bizarro）变身与空间跳跃/十字传送门系统。
成为英雄后的核心体验：
超强体质（高生命、高抗性、免疫多数负面效果、极慢饥饿）
自由飞行 + 可调节飞行速度
多种主动技能（通过能力芯片菜单或专属物品触发）
实验室采集血液 → 逆向研究 → 调配血清
可变成比扎罗形态，获得专属冰系/热系能力
空间跳跃与十字传送门进行远距离位移
主要技能说明
1. 进阶能力芯片菜单（the_boys:hero_power_chip）
右键打开菜单，可使用以下技能（有冷却）：
技能
作用
冰冻呼吸
向前方喷射寒气。水面结冰、地面覆霜，范围内生物被定身并持续受到冻伤伤害。
音爆拍掌
蓄力后双手猛拍，释放多道环形冲击波，对周围实体造成伤害并破坏方块。
雷电风暴
以瞄准点为中心，在较大范围内持续召唤落雷，持续约30秒。
火焰呼吸
在瞄准点周围大范围点燃难以熄灭的火焰，持续约30秒。
超级感官（透视）
开启X射线透视，持续约30秒，可看穿周围方块与实体。
超级呼吸
向前方释放高密度螺旋风柱，形成具有宽度和高度的龙卷风效果。
超级旋转
进入高速旋转状态，持续钻碎身边及准心前方的可破坏方块，持续约10秒。
超级冲刺
沿准心方向短促高速推进，路径上可破坏方块，带有速度风线特效。
双手固定目标 · 超人镭射眼
抓住前方目标后，双手固定并用镭射眼贯穿目标。
空间跳跃
打开方向与距离选择菜单，生成十字传送门进行远距离跳跃/传送。
2. 比扎罗形态专属技能
使用丧尸催化剂（僵尸注射器）变身为比扎罗后，菜单技能变为：
冷冻射线：发射冰系射线，冻结路径上的水与地面，并对命中生物施加减速。
热呼吸：比扎罗版本的火焰呼吸。
3. 其他核心能力 / 物品
飞行系统：获得英雄身份后可自由飞行，支持速度调节与空中冲击波加速。
英雄镭射眼（hero_laser）：持续发射可破坏方块的激光。
抓取（hero_take）：抓住附近实体并固定在身前，高速飞行时会进行位置预测以保持同步。
超级速度（superspeed）：切换开启/关闭，大幅提升移动速度。
超级听力 / 雷达：扫描并标记附近生物，显示最近威胁的距离与坐标。
蓄力重拳 / 穿隧重击（hero_combat）：蓄力后打出高伤害与更远范围，可破坏路径上的方块。
金刚之躯：可在说明书中开关，开启后抗性大幅提升。
4. 实验室系统
通过说明书可查看完整流程：
使用血液提取机抽取「超人血液瓶」
在逆向研究台研究材料，制作临时强化血清或抑制剂
使用实验工作台制作各类机器与基础材料
相关物品包括：空针管、超人血液瓶、临时强化血清、抑制剂、能源晶体等。
